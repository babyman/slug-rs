# Agent Development

This directory contains repository-local guidance for Codex work. Root
`AGENTS.md` is authoritative; these files provide the detailed procedure for a
specific type of change.

- `workflows/language-change.md` defines the change and verification sequence
  for Slug syntax and semantics.
- `../docs/decisions/README.md` defines when a durable decision record is
  required and how to write one.

Keep workflows executable and specific to this repository. Do not duplicate
general coding advice that already belongs in `AGENTS.md`.
